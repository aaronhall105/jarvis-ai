# Install Jarvis v16.2.0

Upload `jarvis-conditional-actions-v16.2.0-core.tar.gz` to `/home/aaron/jarvis`, then run:

```bash
cd ~/jarvis && \
tar -xzf jarvis-conditional-actions-v16.2.0-core.tar.gz && \
chmod +x tools/install_conditional_actions_v16_2_0.sh && \
./tools/install_conditional_actions_v16_2_0.sh
```

No Home Assistant integration update is required. Assist remains on cumulative v1.5.4.

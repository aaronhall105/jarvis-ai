# Install Jarvis v16.1.0

Upload `jarvis-recurring-schedules-v16.1.0-core.tar.gz` to `/home/aaron/jarvis`.

Run on the Ubuntu Jarvis PC:

```bash
cd ~/jarvis && \
tar -xzf jarvis-recurring-schedules-v16.1.0-core.tar.gz && \
chmod +x tools/install_recurring_schedules_v16_1_0.sh && \
./tools/install_recurring_schedules_v16_1_0.sh
```

The installer requires Jarvis v16.0.7 and does not require a new Home Assistant Assist installation.

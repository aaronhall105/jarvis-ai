# Changelog

## Current prerelease

### v19.0.0-alpha25 — unified product revision

Alpha25 publishes Core, Developer gateway, Android Phone, Wear OS, product
manifest, and OTA metadata from one approved `jarvis/unified-production`
revision. It preserves the current Phone/Watch product lineage and includes
installed OTA integrity reporting.

See [the complete alpha25 release notes](docs/releases/CHANGES_V19_0_0_ALPHA25.md)
and the [published GitHub prerelease](https://github.com/aaronhall105/jarvis-ai/releases/tag/v19.0.0-alpha25).

Core application version remains `3.7.0`; realtime protocol remains `2`.

# Jarvis v16.3.0 changes

- Adds persistent, owner-scoped named routines.
- Adds immediate multi-step scenes without saving them.
- Adds exact sequential action plans shared by one-off tasks, recurring schedules and conditional rules.
- Supports lights, switches, TV power, configured TV apps, Home Assistant scripts/automations, short delays, mobile notifications and living-room announcements.
- Stops a routine at the first failed step and records per-step results.
- Adds routine list, show, history, rename, disable, enable and delete commands.
- Preserves v16.2.0 Conditional Actions cumulatively for systems upgrading directly from v16.1.0.
- Keeps Home Assistant Assist integration v1.5.4 and config-entry version 2 unchanged.

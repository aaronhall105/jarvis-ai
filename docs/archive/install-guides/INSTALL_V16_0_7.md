# Install Jarvis v16.0.7

Ubuntu Jarvis PC:

```bash
cd ~/jarvis
tar -xzf jarvis-smart-audio-gate-v16.0.7-core.tar.gz
chmod +x tools/install_smart_audio_gate_v16_0_7.sh
./tools/install_smart_audio_gate_v16_0_7.sh
```

Then install Assist v1.5.4 from the Home Assistant Terminal using the command printed by the installer.

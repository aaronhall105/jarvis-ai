# Install Jarvis Android Voice Client v17.1.0-r1

Upload the archive to `/home/aaron/jarvis`, extract it and run:

```bash
cd ~/jarvis
tar -xzf jarvis-android-voice-client-v17.1.0-r1-core.tar.gz
chmod +x tools/install_android_voice_client_v17_1_0_r1.sh
./tools/install_android_voice_client_v17_1_0_r1.sh
```

Java is optional on the Jarvis server. GitHub Actions remains the authoritative Android unit-test and APK compilation environment.

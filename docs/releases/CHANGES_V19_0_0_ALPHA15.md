# Jarvis 19.0.0-alpha15

Alpha15 adds Jarvis's secure Android OTA updater: Alpha/Beta/Stable feeds, manual and periodic checks, optional unmetered automatic download, release notes and progress, layered APK integrity/signing checks, notifications, update history, and Android's supported user-approved in-place installation flow.

Core application version remains 3.7.0 and realtime protocol remains 2 because the updater introduces no Core API or realtime incompatibility.
